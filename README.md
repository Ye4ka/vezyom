# Везём

Адаптивный интерфейс сервиса доставки блюд.
Лабораторная работа №1, ПМ.09 — «Адаптивный интерфейс веб-приложения», вариант 8
(«Сервис доставки еды»).

## Концепция

«Везём» 0 агрегатор доставки, как Купер/Яндекс.Еда: сначала клиент выбирает
ресторан в каталоге, а затем - конкретные блюда из его меню.

## Стек

- React + React Router — client-side роутинг
- Tailwind CSS — стили, светлая/тёмная тема
- Vite — сборка и dev-сервер
- lucide-react — иконки
- React Context + localStorage — имитация сессии авторизации

## Страницы (роуты)

| Роут | Страница | Описание |
|------|----------|----------|
| `/` | Главная | Промо-слайдер, популярные рестораны, блок «Как это работает» |
| `/catalog` | Каталог | Поиск, фильтр по кухне, сортировка |
| `/catalog/:restaurantId` | Меню ресторана | Категории блюд, поиск, корзина |
| `/register` | Регистрация | Форма с клиентской валидацией |
| `/login` | Авторизация | Форма входа |
| `/profile` | Личный кабинет | Заглушка, доступна только после входа |
| `*` | 404 | Страница не найдена |

## Фичи

- Светлая/тёмная тема с сохранением выбора (`localStorage`)
- Поиск и фильтрация ресторанов по названию/кухне, сортировка
- Поиск и фильтрация блюд по категориям внутри меню ресторана
- Корзина со счётчиком количества (в рамках одной страницы ресторана)
- Форма регистрации: ФИО, email, логин, пароль, повтор пароля — валидация на `blur` и при отправке
- Форма входа с имитацией сессии через Context + `localStorage`
- Промо-слайдер с автопрокруткой, свайпом, точками-индикаторами
- Адаптивное мобильное меню (бургер)
- Прокрутка наверх при смене страницы и по кнопке
